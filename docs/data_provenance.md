# Data provenance

## Default self-contained profiles

The default hourly demand and renewable profiles are synthetic shapes generated by the project. They are modelling assumptions, not measurements. National demand scale and selected renewable-capacity totals are calibrated to public Dutch statistics as described in `config/model_config.yaml`; provincial allocation, topology, corridor ratings, and congestion windows remain synthetic.

## Optional OPSD profiles

`scripts/download_opsd_profiles.py` downloads an Open Power System Data time-series file when explicitly requested. Record the source URL, access date, selected columns, geographic coverage, transformations, and upstream licence alongside any reference run that uses it. Downloaded data are not required for the default test workflow.

## Reproducibility rule

Reference results must identify the configuration, source-data mode, code commit, solver status, and software environment. Never describe a configured source as used unless the run metadata confirms it was consumed.
